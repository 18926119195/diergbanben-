> 日期：2026-08-17

---

## 0. 今日已钉死的思路（槽 → 回溯）

**一句话：** 先把版面切成可哈希的**槽**并登记进 A 表，之后任意结论才能**真回溯**到同一块物理领土——人看绿框真视觉，机器看同槽读值 T。不是「答完再贴 citation」。

```text
切割排放（今天能做到）
  → 每一刀 = 一个槽 PlaceAtom
       key* = doc|slot|p{page}|k{k}
       AABB = 锁定的 page_norm 框（人侧回溯高亮只读它）
       T    = 同条提案 content（机器读值；禁止事后用字重绑框）
  → V_q / 圈选只是在已建槽上找门牌
  → 进房 / Bundle / 方向结论都挂在 key*
  → 回溯：结论 → key* → 翻页 + 绿框(AABB) ∥ 展示 T / 读值%
```

| 思路 | 含义 | 今天验证状态 |
|------|------|----------------|
| **弄出槽** | 排放原子先落地：框先验 + 同条字 + 稳定门牌 | ✅ 尺对齐后绿框能罩住对应段 |
| **能回溯** | 从结论/候选点回槽，高亮只读登记 AABB | ✅ 同源 `imageUrl` 上共位 |
| **共指锁** | 人机不共享「懂意思」，共享「同一 `key*`」 | ✅ 双通道：框给看、T 给读 |
| **框先于字** | geom 先锁；T 填进已知槽，不反向用字找框 | ✅ 主路径；裁切再 OCR 仅无字退回 |
| **贴合≠尺** | 刀口松紧属 layout 质量；尺过关 ≠ 框贴死字边 | ✅ 已区分验收标准 |
| **预选≠推理** | 找槽 / 进房在前；主模型只在留房不复用时调用 | 房内复用路径待你继续验 |

**和常见 RAG grounding 的差：** 市场多是答完再反查出处；本试点是**先有槽身份，再问、再推、再回溯到同一槽**。

## 1. 切割即登记（已验证主路径）

渲染页图 `page.imageUrl` ≡ OCR / 排放真源（同源）。对开页 = 一张图含左右两页，不是两套 URL。

```text
1. ProposeRegions：整页 layout_parsing → 有序区域（bbox + 同条 content）
2. 对每个区域：geom = AABB(page_norm 0–1000) 立刻锁定
3. T0/T：优先用「与该 bbox 同条提案」的 content
   （裁切再 OCR 仅在提案无字时退回；避免二次认字把框外墨迹拼进 T）
4. OcrBlock = { slotK=k, bbox=geom, sourceContent=T0, content=T, cutBound }
5. A1：1 块 = 1 槽门牌 doc|slot|p{page}|k{k}（OCR/PDF 禁止 structureChunk 合并）
```

**坐标尺（已验证）：** 智谱 layout 实况为相对页图像素；`normalizeBboxToThousand` 在已知宽高时按像素→0–1000（禁止把「数值≤1000」误当已千分格）。  
高亮 / 读值% 只读槽 AABB，不以字重绑框。

**贴合松紧：** layout 提案刀口质量；**不属**本试点「尺是否对齐」的必过项。人侧以绿框为准审计。

## 2. 预选 ≠ 主推理（找槽 → 进房）

```text
V_q 搜槽内 T → 返回 slot 哈希 + 读值 + AABB + 读值%
→ 用户确认（点候选 = 认这口槽）→ 对话闭包（memberKeys）→ Bundle / 复用
→ 回溯 UI：绿框 = 该槽登记 AABB（不是临时用字重画的框）
```

## 3. 房内交互（现行 · 已落地）

| 动作 | 行为 |
|------|------|
| 房内比对方向 | 闭包内方向 × 问题探针 → Top 命中 |
| 复用（停止） | 硬短路，**不调**主模型 |
| 排除并直接推理 | 写入 `forbid_directions` 后**自动**留房推理 |
| 取消排除 | 仅从清单移除，不触发推理 |
| UI | 「近似方向·审核」「最近结论」在**中央下方**半透明浮层（`ReasoningFloorDock`） |
